# Робот К-79М 

**К-79М** — модернизированная модель робота К-79 — предназначена для игры
пользователя и исследования возможностей перемещения по двумерной
математической плоскости с помощью буквенных команд.

Пакет [robot](./src/main/java/robot) содержит компоненты Робота:
* [Robot](./src/main/java/robot/Robot.java) — модель шагающей сущности 'Робот'
* [Position](./src/main/java/robot/Position.java) — клетка поля положений, по которому
  происходит движение, является целочисленной координатой на декартовой плоскости `(x, y)`.
* [Direction](./src/main/java/robot/Direction.java) — ориентация в
  пространстве (направление движения) Робота: `НАВЕРХ`/`НАПРАВО`/`ВНИЗ`/`НАЛЕВО`—
  соответственно видимым направлениям на экране пользователя.

Класс [TestSite](./src/main/java/TestSite.java) представляет модель испытательного полигона,
именно он запускается и создаёт модель робота, с которым вы будете работать.

### Работа программы
Пользователю предлагается выбрать режим работы, для этого нужно набрать на клавиатуре
команду и нажать 'Ввод'. Список команд `Главного Меню`:
* 1 = _свободное управление_
* 2 = _прогнать последовательность_
* 3 = _демо-последовательность №1 (SSLSLSLSSRSRS)_
* 4 = _демо-последовательность №2 (LSSSS)_
* X = _выход_

**Демо №1 и №2** представляют тест-кейсы, описанные в условии задачи на сайте `acmp.ru`.

**Прогон последовательности команд** — _прогоняет_ робота по тест-кейсу, вводимому с клавиатуры
(аналогично предложенным _демо_). В конце _прогона_ робот отчитывается о выполненных командах,
посещённых полях и полях, которые он в ходе этого прогона посетил НЕ единожды.

### Интерактивный режим
В начале каждого шага Робот сообщает своё положение и направление.

Он принимает с клавиатуры следующие команды:
*  S = шаг вперёд в текущем направлении
*  L = поворот направления налево (против часовой стрелки)
*  R = поворот направления направо (по часовой стрелке)
*  H = показать пройденный маршрут
*  Z = перезагрузка (сброс статистики и возвращение в `[0, 0]`)
*  Х = конец испытания 

По выходу из режима "свободного управления" также отображается память робота (выполненные 
команды, пройденный путь, найденные пересечения), и затем очищается.
